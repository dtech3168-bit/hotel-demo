# Belvedere Travelodge — Hotel Website

Belvedere Travelodge is a responsive hotel website designed to showcase a modern accommodation business, its rooms, amenities, guest experience, and direct booking interface.

The project focuses on building a polished hospitality experience with responsive layouts, interactive booking UI, room presentation, and conversion-focused frontend design.

> **Project status:** Frontend demo. The booking and contact interfaces are currently client-side only and are not connected to a backend, database, authentication, or payment system.

## Tech Stack

* Vanilla JavaScript

* DOM Manipulation

## Room Types

The website presents three room categories:

* Standard Room
* Deluxe Room
* Executive Suite

Each room includes a visual preview, amenities, and nightly pricing.

## Booking Interface

The project includes a client-side booking modal where users can enter:

* Full name
* Email address
* Phone number
* Room type
* Check-in date
* Check-out date

The interface demonstrates the frontend booking flow, but submissions are not currently persisted to a backend.
